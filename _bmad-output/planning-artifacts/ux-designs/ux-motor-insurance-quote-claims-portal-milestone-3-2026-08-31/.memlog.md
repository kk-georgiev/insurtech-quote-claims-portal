- (decision) Lean Fast-path run, no subagents, no reviewer gate, no creative tools - explicit user instruction. Sources read directly in the parent: M3 PRD, frontend/src/index.css tokens, components/ui/* API, i18n catalogs.
- (decision) Foundation names an existing UI system: the Milestone 2 design system (Tailwind v4 CSS-first tokens + components/ui). DESIGN.md documents the inherited identity by reference and adds only the M3 delta; no new visual identity authored. EXPERIENCE.md carries the milestone's weight.
- (decision) IA: two new client branches /quotes(/:id) and /policies(/:id). Acceptance happens only on quote detail, never inline in the list - a contract is not issued from a list row, and the user must have seen the breakdown first.
- (decision) Acceptance is a screen section, not a modal. Reasons: identity+vehicle are real input not yes/no; a modal hides the breakdown at the moment it matters; no modal primitive exists and adding one violates the no-redesign constraint.
- (decision) Badge is the only new component - M2 fixed the AD-6 status color vocabulary without a consumer; M3 is that consumer. Text always carries the meaning, color reinforces.
- (decision) Expired and accepted quotes REPLACE the acceptance form rather than disabling it, and keep the breakdown visible. A disabled button invites hunting for what would enable it.
- (decision) Expired policy renders neutral, not danger: a policy running its full term is the successful outcome. Expired quote renders danger: a lost opportunity worth acting on.
- (decision) Lists are single-column cards at every width - no table. The desktop-obvious table is rejected because of the 375px floor.
- (override) Accessibility is a documented floor, not an audit - product owner deprioritized it (M3 PRD Q-3). The floor is what the M2 primitives give for free and must not regress; no new a11y work planned.
- (decision) i18n delta for M3: new namespaces quotes.* and policies.*; dates follow the active language's convention; money renders identically in both languages with an explicit EUR from the API, never locale-derived.
- (assumption) No mocks or wireframes rendered - lean run, all surfaces spine-only. Quote detail is the screen to mock first if implementation needs a visual reference.
- (event) spines finalized
